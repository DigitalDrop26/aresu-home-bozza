# Formaggi Aresu — bozza home page

Bozza della nuova home di formaggiaresu.com, progettata da DROP.
Pagine statiche: `index.html` (home), `azienda.html`, `formaggi.html`, `territorio.html` + `img/` + `video/` + `font/`.
Testi presi solo dalle fonti del cliente: sito attuale, catalogo, company profile, foglio «Materiale testuale».
Animazioni con GSAP + ScrollTrigger e scroll fluido con Lenis (da CDN).

- **In locale** i titoli usano Loew, il carattere del brand (file non inclusi nel repo: licenza commerciale).
- **Online** il workflow `.github/workflows/deploy.yml` toglie le `@font-face` di Loew e i titoli usano Montserrat (OFL).
